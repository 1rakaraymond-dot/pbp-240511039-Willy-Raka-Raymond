# ANALISIS PLATFORM WEB, DESKTOP, DAN MOBILE

## 1. Pendahuluan

Dalam pengembangan perangkat lunak, terdapat berbagai platform yang digunakan untuk menjalankan aplikasi, di antaranya Web, Desktop, dan Mobile. Setiap platform memiliki karakteristik, arsitektur, bahasa pemrograman, metode distribusi, keunggulan, serta keterbatasan yang berbeda.

Analisis ini bertujuan untuk memahami perbedaan karakteristik ketiga platform tersebut sebagai dasar dalam menentukan teknologi yang sesuai untuk pengembangan aplikasi.

## 2. Tabel Analisis Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| **Arsitektur** | Client-server, aplikasi diakses melalui browser dan berkomunikasi dengan server. | Aplikasi berjalan secara lokal pada sistem operasi komputer, dapat terhubung ke server. | Aplikasi berjalan pada perangkat smartphone atau tablet dengan memanfaatkan fitur sistem operasi mobile. |
| **Bahasa Utama** | HTML, CSS, JavaScript, serta bahasa backend seperti JavaScript, PHP, atau Python. | Java, C#, C++, Python, dan bahasa lainnya. | Kotlin dan Java untuk Android, Swift untuk iOS, serta Dart untuk Flutter. |
| **Distribusi** | Melalui hosting atau server dan diakses menggunakan URL browser. | Melalui installer, file executable, atau toko aplikasi desktop. | Melalui Google Play Store, Apple App Store, atau instalasi langsung. |
| **Keunggulan** | Mudah diakses dari berbagai perangkat, tidak memerlukan instalasi khusus, dan pembaruan dapat dilakukan melalui server. | Dapat memanfaatkan sumber daya komputer secara langsung, mendukung penggunaan offline, dan memiliki integrasi sistem operasi yang lebih luas. | Portabel, mudah digunakan, serta dapat memanfaatkan kamera, GPS, sensor, dan notifikasi perangkat. |
| **Keterbatasan** | Bergantung pada browser, koneksi internet untuk fitur berbasis server, dan memiliki batasan akses terhadap perangkat. | Perlu instalasi, kompatibilitas dapat berbeda antar sistem operasi, dan pembaruan perlu didistribusikan kepada pengguna. | Memiliki keterbatasan sumber daya baterai dan perangkat, serta pengembangan dapat memerlukan penyesuaian untuk berbagai ukuran layar dan sistem operasi. |
| **Contoh Aplikasi** | Google Docs, Gmail, dan YouTube. | Microsoft Word, Visual Studio Code, dan IntelliJ IDEA. | WhatsApp, Instagram, dan Google Maps. |

## 3. Kesimpulan

Berdasarkan hasil analisis, platform Web, Desktop, dan Mobile memiliki fungsi dan karakteristik yang berbeda.

Platform Web lebih sesuai untuk aplikasi yang membutuhkan akses luas melalui browser. Platform Desktop cocok untuk aplikasi yang membutuhkan integrasi dengan sistem operasi dan kemampuan pemrosesan lokal. Sementara itu, platform Mobile lebih sesuai untuk aplikasi yang digunakan secara praktis melalui smartphone dan membutuhkan akses terhadap fitur perangkat.

Dengan memahami perbedaan tersebut, pengembang dapat memilih platform dan teknologi yang sesuai dengan kebutuhan aplikasi yang akan dikembangkan.
